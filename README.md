# CodeAlpha_WebScraping
A beginner-friendly web scraping project completed as part of the CodeAlpha Data Analytics Internship. The project involves extracting relevant data from a public website, organizing it into a structured dataset, and documenting the workflow for analysis readiness.

📌 Project Objective
The objective of this task is to perform web scraping on a public website and collect meaningful data in a structured format for analysis.

🌐 Data Source
Website: "https://realpython.github.io/fake-jobs/"
Data Collected: Job Title, Copany Name and Job Location
🛠 Tools & Technologies Used
Python
Requests
BeautifulSoup
Pandas
📂 Project Description
Sent HTTP requests to the target website
Parsed HTML content using BeautifulSoup
Extracted  Job Title, Copany Name and Job Location
Stored the extracted data into a CSV file for further analysis
🎯 Learning Outcomes
Understanding website structure (HTML)
Practical experience with web scraping
Data collection and preprocessing skills
Preparing datasets for exploratory data analysis
⭐ This project strengthened my foundational knowledge of data analytics and web data extraction.
